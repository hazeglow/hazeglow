# hazeglow for coding agents

**Using hazeglow in an app:** before adding or changing a gradient, read `skills/hazeglow/SKILL.md` in this package. It covers when to use it, how to place it behind content, theming with CSS variables and the rules that keep it fast. The full API and config reference is `README.md`. The same skill installs into a project with `npx skills add hazeglow/hazeglow`.

**Working on the hazeglow repository itself:** follow `CLAUDE.md` at the repository root. It has the pre-push checks, the changeset rule and the public API that must not change.
